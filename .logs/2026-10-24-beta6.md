# Beta 6 voice-answer implementation — 2026-10-24

Started beta-6 from accepted v0.5.0/main (6e6e965). Version 0.6.0. No Beta 5 tag/main changes or deployment.

## Implementation

- Native SpeechRecognition/webkitSpeechRecognition adapter with ja-JP final results, bounded alternatives/restarts, startup timeout, duplicate/late callback suppression, abort on scoring/pause/visibility/exit and fatal-error fallback to buttons without scoring an access failure.
- Strict solfege/enharmonic and chord vocabulary parsing. Lv1 12 classes; Lv2 ordered pair across one/two utterances; Lv3 48 root/quality classes. Conflicting candidates remain unresolved. Correct answers are not used to disambiguate recognition. Explicit major/minor phrases required instead of ambiguous “em seven”.
- Default remains buttons. Voice requires in-app consent describing possible browser/OS recognition-service transmission; recording is separate and OFF by default. Settings include microphone test, speech examples and optional automatic progression. Voice mode can auto-run an entire session and retains button controls.
- Recognition starts only after problem/cue playback; answer time begins when the microphone is ready. Existing 8/10/8-second limits, shortened session sizes, range/voicing and scoring are preserved.
- Optional recorder retains only fully unanswered samples, max 10 seconds/1MiB each and latest two globally. Valid/partial answers and cancelled samples are discarded. Oversize data is discarded rather than truncated into a corrupt file. Streams are stopped on every finalization/cancellation path.
- IndexedDB v2 adds debugAudio while preserving state. State/Blob writes, FIFO eviction, deletion and JSON import clearing are atomic. Blob data stays outside JSON; support exposes audio controls/file download. Unanswered transcripts/errors live only in the two-entry FIFO, not every session history. Metadata text is bounded to 160 characters.
- JSON import clears recording Blobs and resets voice/recording consent; importing settings cannot authorize a microphone. Beta 5 DB migration and import privacy are tested. Downgrade to Beta 5 in the same browser profile is unsupported; README recommends JSON backup and separate profiles for old-version comparison.
