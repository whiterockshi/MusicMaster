# MusicSensor — Beta 4

十二平均律の12音を聴いて、CDEのボタンで答える個人用トレーニング。まずはPC上で試すためのローカルWeb版です。

## 起動（WSL2 / Linux / macOS）

1. Node.js **24.19.0**（24系LTS）とnpmを用意してください。PythonやCondaの有効化は不要です。nvmが既にある場合は、このディレクトリで `nvm install` → `nvm use` が使えます。
2. このプロジェクトを作業場所へ配置し、そのディレクトリで次を実行します。クラウドの配置先は `/workspace/MusicMaster`、WSLの候補は `/home/tamago/AppDev/MusicSensor` です。既存のファイルを上書きしないでください。

```bash
node --version
npm ci
npm run dev
```

3. ターミナルに表示される Local のアドレスをPCブラウザで開きます。WSLの場合はWindows側のブラウザで開けます。
4. 終了はターミナルで `Ctrl+C`。再開するときは同じディレクトリで `npm run dev` を実行します。

Node.jsは開発ツールを動かす実行環境です。TypeScriptをブラウザ用JavaScriptへ変換するのはVite等が担当し、コンパイラを別途選定する必要はありません。

## ベータ4で使える機能

- スタート → ステージ選択 / 復習 / サポートの画面階層。
- Lv1：C4〜B4の全12音を必ず含む20問（各1〜2回、順序はランダム）。A4=440 Hz、サイン波。
- 「音を聴く」→案内→2秒待機→1秒発音→合図→8秒間のボタン回答。正解5点、100点満点。
- 正誤の効果音、結果表示。一時停止から同じ問題を再生。画面を隠すと一時停止します。
- 案内・結果の読み上げは端末内の日本語音声が利用できる場合のみ。ない場合は画面表示と合図で進めます。外部の読み上げサービスは利用しません。
- IndexedDBへの問題単位の保存。再読込で進行中セッションは中断履歴になります（続きからの再開は未対応）。
- 復習待ちの全音をシャッフルして各1回出題。正解で待ちから除き、誤答履歴は保持。
- 未回答は0点、復習へ新規追加せず、最新2件のメタデータをFIFO保存。
- レベル別に切り替える苦手分析（Lv2/3は準備中）。Lv1は音別の正解率、誤回答先の一覧。5回答未満はデータ不足表示。
- 通常練習だけを表示する月カレンダー・日別結果（復習は一覧・マーカー・件数から除外）、通常Lv1の日別平均点グラフ。復習・中断はグラフ集計から除外。
- JSONバックアップ・復元（全置換・確認あり）、セッション結果CSV出力、未回答例の確認・削除・出力。

Lv2/3は「準備中」です。音声回答・録音・インカム対応・Web公開は後のベータで扱います。外部への自動データ送信、マイク・カメラ権限要求はありません。iPhone/Safariでの実音・機器確認は未実施です。画面サイズを模擬したChromiumテストは実機確認の代替ではありません。

記録は**ブラウザ・プロファイル・アクセス先（ホストとポート）ごと**に保存されます。同じ起動先を使い、ブラウザデータ削除や公開先への移行前にはJSONを保存してください。プライベートブラウズでは保存が維持されない場合があります。複数タブの同時プレイは未対応です。JSON復元は現在のデータを置換するため、先にバックアップしてください。

## ベータ4の確認をお願いします

室内・停車中、PCのスピーカーまたはヘッドホンで確認してください。

1. 「トレーニングをはじめる」→「Lv1を開始する」→「音を聴く」で音が聞こえるか。
2. 音名を選ぶと正誤表示と効果音が一致するか。「わからない」または時間切れで未回答になるか。
3. 20問を終え、結果が正解数×5点になっているか。
4. 再読込しても「復習」に誤答が残るか。復習で正解すると待ち一覧から消え、過去の誤答履歴には残るか。
5. 「復習」→「カレンダー」で日別結果とLv1グラフを見られるか。
6. 「サポート」で未回答例が最大2件になっているか。JSONを保存できるか。

問題があれば、OS・ブラウザ名、操作した画面、期待した結果、実際の結果を教えてください。ベータ4のフィードバックを反映後、ベータ5へ進みます。

## 開発者向け検証

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

システムのChromiumを利用する場合（クラウドではこちらで検証済み）：

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

ブラウザのダウンロードにはPlaywrightの配布先へのアクセスが必要です。このクラウドでは配布先が許可されていなかったため、既存の `/usr/bin/chromium` を使用しています。

ビルド結果をローカル確認する場合は `npm run preview` を実行し、ターミナルのLocalアドレスを開いてください。`dist/index.html` の直接ダブルクリックでは起動しません。

設計・ロードマップは [PLAN.md](PLAN.md)、エージェントの作業方針は [AGENTS.md](AGENTS.md) を参照してください。
